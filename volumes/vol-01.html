<html> — Root Element

Document Metadata standard

The root element of every HTML document.

<html> is the top-level element that wraps everything else on the page. It normally has two children: <head> (metadata the browser uses) and <body> (the visible content).

Attributes

AttributeTypeDescription
langBCP-47 codeDeclares the page language, e.g. lang="en" or lang="ar". Used by screen readers, speech and search engines.
dirltr / rtlOptional. Sets the base text direction; default comes from lang.
xmlnsURLNot required in HTML5. Historically declared the HTML namespace on XHTML.

Example

<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

Live result

Live result
<html> → <head> + <body>

Notes & best practices

  • Always set lang — it is your first accessibility and SEO win.
  • Exactly one <html> element per document.

Related: <head> · <body>

<head> — Document Head

Document Metadata standard

Container for all machine-oriented information about the document.

<head> holds metadata that is not rendered on the page: the title, character encoding, viewport, stylesheets, scripts, and other machine-readable information. It sits between <html> and <body>.

Example

<head>
  <meta charset="UTF-8">
  <title>My Page</title>
</head>

Live result

Live result
<head> = title + meta + link + style + script (invisible)

Notes & best practices

  • Never put visible content inside <head>.
  • Order: charset meta should be in the first 1024 bytes of the file.

<base> — Document Base

Document Metadata standard

Sets the base URL for all relative URLs on the page.

<base> is optional. When present, every relative URL (links, images, stylesheets) is resolved against its href. It can also define the default target for links. Use with care — it changes the meaning of every relative URL.

Attributes

AttributeTypeDescription
hrefURLBase URL. Must be an absolute URL if target is used.
targetwindow namee.g. _blank — default target for all links without a target attribute.

Example

<base href="https://docs.example.com/" target="_blank">

Live result

Live result
base URL = https://docs.example.com/ → <img src="a.png"> loads docs.example.com/a.png

Notes & best practices

  • Only one <base> per document, and it must come before any element with a URL.

Related: <head>

<link> — External Resource Link

Document Metadata standard

Links an external resource, most commonly a stylesheet.

<link> connects the document to outside resources: CSS stylesheets, site icons (favicons), preloads of fonts and scripts, and feed manifests. In <head> it is the standard way to include a stylesheet.

Attributes

AttributeTypeDescription
relkeywordRelationship: stylesheet, icon, preload, preconnect, manifest, alternate, dns-prefetch.
hrefURLURL of the linked resource.
typeMIME typee.g. text/css for stylesheets.
mediamedia querye.g. media="print" or media="(max-width:600px)".
asresource typeFor preload/preconnect: style, script, font, image, fetch, script.
crossoriginkeywordanonymous / use-credentials — for cross-origin preload.

Example

<link rel="stylesheet" href="style.css">
<link rel="icon" href="logo.svg">

Live result

Live result
style.css → linked

Notes & best practices

  • rel="preload" fetches early; rel="preconnect" warms the network connection.
  • Favicon: use <link rel="icon"> before <title>.

<meta> — Metadata

Document Metadata standard

Machine-readable metadata about the document (encoding, viewport, description, authors).

<meta> carries information for the browser, search engines and social networks. Key uses: character set, viewport for mobile, page description, author, theme color, Open Graph and Twitter card tags.

Attributes

AttributeTypeDescription
charsetcharacter setcharset="UTF-8" — should be the very first thing in <head>.
namekeywordviewport, description, author, robots, theme-color, color-scheme, keywords.

http-equivheader namee.g. Content-Security-Policy, refresh, X-UA-Compatible (legacy).

Example

<meta name="viewport" content="width=device-width, initial-scale=1">

<script> — Executable Script

Document Metadata standard

Embeds or references executable JavaScript.

<script> runs JavaScript in the page. It can contain inline code or point to an external file with src. Modern best practice: external file with defer (runs after parsing, in order) or async (runs as soon as downloaded).

Attributes

AttributeTypeDescription
srcURLURL of the external script.
typeMIME typetext/javascript (default), module, text/json (data blocks), text/template.
deferbooleanExternal scripts execute after HTML parsing, in document order.
asyncbooleanExternal scripts execute as soon as they download.
nomodulebooleanSkip this script in browsers that support modules.
crossoriginkeywordanonymous / use-credentials for CORS.

Example

<script src="app.js" defer></script>
<script>
  console.log("hi");
</script>

Live result

Live result
console.log("hi"); → "hi"

Notes & best practices

  • defer keeps scripts from blocking rendering.
  • Place scripts at the end of <body> or use defer — both work; pick one convention.

<template> — Inert Content Template

Document Metadata standard

An inert container of markup that can be cloned by JavaScript.

<template> holds HTML that is not rendered, not executed (scripts do not run, images do not load) until JavaScript clones its content. It is the standard building block for Web Components and JS-driven lists.

Attributes

AttributeTypeDescription
shadowrootmodeopen / closedOptional. If present, the template is the shadow root of a custom element.

Example

<template id="card">
  <div class="card"><h3></h3><p></p></div>
</template>

Live result

Live result
<template> content is inert — rendered only when JS clones it into the DOM

Notes & best practices

  • Content lives in a separate DocumentFragment — access it with template.content.
  • Scripts inside <template> never auto-execute.

<article> — Self-Contained Composition

Document Structure standard

A complete, independent piece of content that makes sense on its own.

<article> is for content that could be distributed or reused independently: a blog post, a news story, a forum comment, a product card, a review. If it would still make sense in an RSS feed or shared page, it is an article.

  <p>Published by Ana on 2026-09-16</p>

    <button formnovalidate>OK</button>
  </form>
</dialog>

  • showModal() gives focus trap + backdrop for free.
  • Use <form method="dialog"> to close with a value (event.returnValue).

<th> — Table Header Cell

Tables standard

A header cell — labels a row or a column.

<th> is a header cell. scope declares what it labels: scope="col" (labels the column below) or scope="row" (labels the row across). Without scope, screen readers can't tell what the header means.
